# Portfolio de Juanvi Rico Pérez

Portfolio personal hecho con HTML, CSS y JavaScript vanilla. Está organizado con la metodología **BEM** para que las clases CSS sean claras y fáciles de mantener.

## Verlo en local

Abre `index.html` en tu navegador. No necesita Node.js, npm ni un proceso de compilación.

## Publicarlo con GitHub Pages

1. Crea un repositorio público en GitHub llamado `portfolio` (o el nombre que prefieras).
2. Descomprime este proyecto y entra en la carpeta `portafolio_web`.
3. Sube el contenido de esa carpeta al nivel raíz del repositorio. `index.html` debe quedar en la raíz, no dentro de otra carpeta.
4. En GitHub, abre **Settings → Pages**.
5. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y la carpeta `/(root)`, y guarda.
6. Espera a que termine la publicación. GitHub mostrará la dirección pública en esa misma sección.

## Estructura

- `index.html`: contenido y estructura semántica.
- `css/style.css`: estilos responsive con nombres BEM (`bloque__elemento--modificador`).
- `js/main.js`: menú móvil accesible.
- `assets/certificados/`: certificados enlazados desde la página.
- `assets/img/`: iconos del sitio.

## Antes de publicarlo

- Revisa que los enlaces externos y los certificados sigan siendo correctos.
- Los proyectos que aparecen como “En desarrollo” o “Proyecto formativo” están descritos como tales para no dar a entender que son productos terminados.
- GitHub Pages publica el contenido del repositorio en internet. No subas contraseñas, claves API, datos privados ni archivos de configuración con secretos.
- Este portfolio es estático; el formulario de contacto anterior se ha omitido para evitar presentar un formulario que dependa de un servicio externo sin configurarlo. El correo y los perfiles públicos siguen disponibles.
